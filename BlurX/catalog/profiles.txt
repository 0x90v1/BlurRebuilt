# BlurX serving profiles: which disc serves a file when several carry it.
# Read by the game at boot (--profile=<name> or BLURX_PROFILE) and by
# code/tools/blurx_catalog/catalog.py (resolve, report). Keywords:
#   profile <name> <description>   starts a profile
#   order <disc> ...               preference order; a disc not listed never serves
#   prefer <glob> <disc> ...       for virtual paths matching <glob> (lower case,
#                                  backslashes, '*' and '?' only), these discs
#                                  come first, then 'order'
#   pin <glob> <disc> ...          matching paths are served only by these discs
#   accept <status> ...            catalog statuses that may be served (default: ok)
# Rules are tried in order; the first matching one applies. A disc serves a file
# only when every copy it holds has an accepted status.
#
# Local changes go in profiles.local.txt beside this file (same syntax, not
# tracked; --profile-overrides=<file> or BLURX_PROFILE_OVERRIDES name another):
# for a profile it names, 'order' and 'accept' replace these and its rules are
# tried before these. No rebuild is needed for either file.
#
# The defaults below come from Blur2Test, which established why a per-asset
# provider is needed and which disc should serve what (AGENTS.md "Asset catalog"):
#   - Nov 10 is missing assets; fill newest-first: Nov 9, Nov 4, Aug 31, then
#     retail Blur 1 (Blur2Test AGENTS.md "Fallback sources"; _notes/disc_resource_map.md).
#   - Weapons come from Aug 31: the PickupType tables in pickups.bin /
#     dynamiceffects.bin / effects.bin, the perk meshes and cycles; a weapon asset
#     only on a November disc (the Icewall meshes) comes from there (Blur2Test
#     AGENTS.md, decided 2026-09-17, gameplay 2026-09-22). The particle textures
#     that bundle uses have no path list in the notes yet; not ruled here.
#   - Audio is the prototypes' own; retail audio is never substituted (Blur2Test
#     README "every graph and every wave is the prototype's own"). Nov 10 ships no
#     audio banks, so Nov 9 is the newest source.
#   - Nov 25 is not in the fallback order (Blur2Test _notes/nov25_disc_assessment.md:
#     "not promoted into the normal asset fallback order"; a damaged rip). It is
#     served only by its own profile, for what only it has.
